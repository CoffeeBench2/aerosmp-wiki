# VR

You can play the whole server in VR. Not a stripped-down mode — the same world,
the same people, the same airships, with your hands on the wheel.

It ships **in the pack**. There's nothing extra to install.

---

## What you need

- A headset that works with SteamVR or Oculus on PC
- The pack installed as normal — see [[getting-started]]
- Enough headroom to run it. VR renders everything twice; see [[performance]]

Launch the pack with your headset connected and runtime running, and Vivecraft
picks it up. If it starts in desktop mode, the headset usually wasn't ready
before the game was.

## Desktop and VR players share the same world

This is the part people don't believe. There is no separate VR server and no
separate lobby. A VR player and a desktop player standing next to each other
see each other properly, animated the way you'd expect rather than as a
T-posing statue.

You can fly a ship someone else built, crew a ship together with one of you in
VR, and nobody has to opt in to anything.

## Flying in VR

Airships are the reason to do this. Taking a helm with your actual hands, on a
deck that pitches under you with real physics, is a different experience from
the same ship on a monitor.

Two pieces of advice, both learned the hard way:

- **Test on a small ship first.** The same rule as [[airships]], but more so —
  learning controls in VR while several thousand blocks up is not the moment
- **Sit down for long flights.** Roomscale is great until a two-hour cargo run

> [!warning] VR is more demanding, and the RAM rule still applies
> Rendering twice does not mean allocating twice. **5–8 GB is still the answer**
> — over-allocating crashes with no crash report whether you're in VR or not.
> See [[performance]].

## If it won't start in VR

1. **Start SteamVR (or your runtime) first**, then launch the game
2. **Check the headset is actually active** — not asleep on a desk
3. **Try desktop mode first.** If the pack won't run flat, it won't run in VR;
   fix that first
4. Still stuck? **[Discord](https://discord.gg/AnFUh5vTz6)**, with your headset
   model and runtime
