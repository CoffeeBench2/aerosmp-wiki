# Getting Started

## 1. Install the pack

There are two ways in, and they work slightly differently.

### Modrinth (recommended)

Install **Coffee's Create: Aeronautics SMP** through the Modrinth App, Prism
Launcher, ATLauncher, or any launcher that accepts an `.mrpack`. Everything you
need is bundled — nothing else to download.

### CurseForge

Install **Coffees Create Aeronautics SMP** from the CurseForge app.

> [!important] CurseForge installs need one extra file
> The CurseForge version ships **without the Aero Core mod**, so you won't get
> the in-game updater or the server menu. Grab the Core jar from our
> **[Discord](https://discord.gg/AnFUh5vTz6)** and drop it into your instance's
> `mods` folder.
>
> Without it the pack still runs — you just have to update manually every time.

## 2. Give it enough RAM

**Allocate 5–8 GB.**

More is *not* better here. Over-allocating starves the graphics driver and
Distant Horizons of memory outside the Java heap, and the game dies with no
crash report — the log just stops. If your game vanishes during loading with no
error, this is almost always why. Come back down to 8 GB.

| RAM | Result |
|---|---|
| Under 5 GB | Runs out of memory, stutters badly |
| **5–8 GB** | **What you want** |
| Over 10 GB | Native crashes with no crash report |

If the pack still runs badly after this, **[[performance]]** has the rest —
Potato mode, shaders, and getting your frame rate back.

## 3. Join

Add the server:

```
coffeeaerosmp.duckdns.org
```

No port needed.

## 4. First login

You'll arrive in the **lobby** before you reach the world.

- **Offline (cracked) players** register a password on first join and use
  `/login <password>` afterwards. You have **3 minutes** to log in before you're
  kicked — just reconnect if that happens.
- **Premium players** are verified automatically.

Once you're through, `/spawn` takes you into the world. Your first `/spawn` also
grants a one-time starter payment of **300 spurs**.

## 5. Before you build anything

Read **[[claims]]**. Unclaimed builds are not protected, and there's one rule
about ships that will cost you your claim if you get it wrong.

## Updating

If you have the Core installed, the pack updates itself — you'll be prompted from
the main menu, and the game closes to apply the update. Let it finish and relaunch.

If you're on CurseForge without the Core, update through the CurseForge app.
